DoctorBook - الواجهة الاحترافية
================================

هذه النسخة تطور واجهة المشروع الحالي مع الإبقاء على بنية ASP.NET Core MVC الموجودة.

أبرز التحديثات:
- تصميم عربي RTL متجاوب مع الهاتف والكمبيوتر.
- صفحة رئيسية جديدة مع صور توضيحية لأطباء، بحث بالتخصص والمدينة.
- أقسام للتخصصات الطبية وخطوات الحجز ومزايا المنصة.
- بطاقات الأطباء وحالات عدم وجود نتائج بدون اختلاق أطباء تجريبيين.
- صفحة دليل الأطباء وصفحة ملف الطبيب بتصميم أحدث.
- الاحتفاظ بروابط تسجيل الدخول والتسجيل والحجوزات ولوحات التحكم الموجودة.

التشغيل:
1) فك الضغط.
2) افتح DoctorBook.csproj في Visual Studio 2022.
3) تأكد من تثبيت .NET 8 SDK واستعادة NuGet packages.
4) اضبط ConnectionStrings:DefaultConnection في appsettings.json.
5) شغّل المشروع.

ملاحظات مهمة:
- صور الأطباء الظاهرة في القسم التعريفي صور توضيحية وليست صورًا لأطباء مسجلين بالمنصة.
- صور الواجهة يتم تحميلها من الإنترنت، لذلك يلزم اتصال إنترنت لظهورها.
- هذه نسخة تطوير واجهة وليست تصريحًا بأن الموقع جاهز للإطلاق العام. يجب اختبار المشروع محليًا، ومراجعة الصلاحيات والبيانات والخصوصية والحجز والاستضافة قبل نشره.
- لم يتمكن بيئة الإنشاء هنا من تشغيل dotnet build لعدم توفر .NET SDK داخل بيئة التنفيذ.
